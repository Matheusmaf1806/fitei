# Fitei

App unificado de treino, dieta e comunicação inteligente para personal trainers e alunos.

## Características

- Dashboard completo para personal trainers
- Home personalizada para alunos com checklist diário
- Módulos de treino (musculação, corrida, natação, funcional, HIIT)
- Sistema de dieta com check de refeições
- Comunicação via WhatsApp
- Gráficos de adesão e progresso
- Sistema de suplementação

## Tecnologias

- Next.js 14
- React 18
- JavaScript puro (sem TypeScript)
- Recharts para gráficos
- CSS puro

## Cores

- Principal: #e53a25
- Escura: #b82e1d
- Mais escura: #8a2216
- Clara: #ed624f
- Mais clara: #f58a7a

## Como executar

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Estrutura

```
/pages          - Páginas e rotas
/components     - Componentes reutilizáveis
/styles         - Estilos globais e módulos
/utils          - Funções utilitárias
/data           - Dados mock/exemplo
```
